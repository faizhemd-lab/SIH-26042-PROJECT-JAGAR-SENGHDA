# SIH-26042-PROJECT-JAGAR-SENGHDA
Project Jagar Senghda is an edge-native, offline-first AI translation and pedagogical assistant built for low-cost Android hardware (2GB RAM) in tribal primary schools. It bridges state languages like Hindi with native mother tongues (Santhali, Mundari, Ho) using real-time voice translation, dual-script rendering, and offline lesson generation.
